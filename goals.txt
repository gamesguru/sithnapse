== Event edges: forward-only plan (added 2026-10-27) ==
Today: SQL `event_edges` is still written (dual write) and read as a fallback;
mtxdb is gated behind `_embedded_event_edges_enabled` and a SQL
`room_edge_source_version` clock. That is the toggle + way-back the goals forbid.

Phase 1 (dead toggle code, no behaviour change):
  - delete EVENT_EDGES_SQL_INSERT_REMOVED, EventEdgesMigrationIncompleteError,
    check_event_edges_migration_complete (+ call in synapse/app/_base.py, + tests)
  - delete event_edges_fwd_is_authoritative; readers stop calling it
Phase 2 (readers mtxdb-only):
  - get_successor_events / is_event_next_to_forward_gap read only mtxdb; drop
    the SQL fallback, repair_edge_index_from_sql and fallback counters
  - drop the room_edge_source_version SQL clock; mtxdb owns its own version
Phase 3 (writers mtxdb-only):
  - persist edges straight to mtxdb; drop the SQL event_edges INSERT, the
    edge_index_outbox + drain, bump_room_edge_source_version
  - make embedded_db_engine=mtxdb non-optional (no `_embedded_*_enabled`)
Phase 4 (schema/migration):
  - decide the one-time import of pre-existing SQL edges (96/05
    event_edges_migrate_mtxdb); then drop event_edges, edge_index_outbox,
    room_edge_source_version tables. Rows only in SQL are lost without it.
Other readers of SQL event_edges still to port: event_federation.py
(~2097, ~2487, ~2857), purge_events.py, stats.py.

Phase 3 survey (2026-10-27): the post-commit put_event_edges_batch to mtxdb
already exists in events.py `_handle_mult_prev_events`; the SQL INSERT, outbox
and source-version bump beside it are the only dual-write left. They cannot go
until every SQL reader of event_edges is ported to mtxdb (backward/forward
batch APIs exist): events_worker.py ~2743 and ~2932; event_federation.py ~2101
(auth/backfill walk), ~2487, ~2857; events.py ~1076, ~1171; purge_events.py
~288, ~553 (join events + edges, need rewriting); events_bg_updates.py ~329,
~899, ~964; _scripts/state_repair.py. Also tests default to no embedded engine,
so mtxdb must become non-optional in test config first.
Order: (a) make embedded engine mandatory in config + test harness, (b) port
readers one at a time, (c) drop SQL insert/outbox/version, (d) drop tables.
